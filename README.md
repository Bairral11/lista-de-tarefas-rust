# Lista de Tarefas em Rust

Meu primeiro projeto em rust.
Lista de tarefas simples operada pelo terminal.

## Sobre

Seu propósito é ajudar o usuário a manter controle de suas tarefas de manaiera minimalista e rápida

## Requisitos

* Inserir tarefa
* Concluir tarefa
* Tarefas concuidas podem são exibidas com um risco para que usuário tenha um feedback
* Remover tarefas
* Listar tarefas
* Contar tarefas (retorna total, conclídas e não concluídas)
